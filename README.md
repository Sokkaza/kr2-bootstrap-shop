## Описание
Многостраничный сайт бильярдного клуба, разработанный с использованием фреймворка Bootstrap 5. Проект включает 5 страниц с адаптивной версткой, готовыми компонентами и интерактивными элементами. Цветовая гамма стилизована под бильярд (зеленое сукно и темное дерево).

## Практическая работа 9
- Создан проект `kr2-bootstrap-shop`.
- Подключен Bootstrap через CDN.
- Создана главная страница на Bootstrap-сетке.
- Реализованы hero-блок, преимущества и карточки.

## Практическая работа 10
- Созданы страницы `catalog.html`, `product.html`, `order.html`, `contacts.html`.
- Добавлена единая Bootstrap-навигация (`navbar`).
- Использованы компоненты: `card`, `btn`, `badge`, `alert`, `modal`, `accordion`.
- Добавлена форма бронирования с `form-control`, `form-select`, `input-group`, `form-check`.
- Обновлен `css/custom.css` (добавлена бильярдная цветовая гамма).
- Добавлена кнопка "Наверх".

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог услуг;
- `product.html` — страница услуги;
- `order.html` — форма бронирования;
- `contacts.html` — контакты и FAQ;
- `css/custom.css` — дополнительные стили;
- `README.md` — описание проекта.

## Как проверить
1. Открыть ссылку GitHub Pages.
2. Проверить навигацию, карточки, модальное окно и адаптивность.
3. Открыть страницу «Услуги» (product.html) для проверки отзывов и таблицы.
4. Открыть страницу «Контакты» (contacts.html) для проверки карты и аккордеона.
