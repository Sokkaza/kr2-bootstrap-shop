# Контрольная работа №2 — Бильярдный клуб

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Автор
ФИО: Гулиев А.А.

## Описание
Многостраничный сайт бильярдного клуба, разработанный с использованием фреймворка Bootstrap 5. Проект включает 5 страниц с адаптивной версткой, готовыми компонентами и интерактивными элементами.

## Практическая работа 9
- Создан проект `kr2-bootstrap-shop`.
- Подключен локальный Bootstrap 5.3.2 (без зависимости от CDN) для стабильной работы в офлайн-среде.
- Создана главная страница на Bootstrap-сетке.
- Реализованы hero-блок, преимущества и карточки.

## Практическая работа 10
- Созданы страницы `catalog.html`, `product.html`, `order.html`, `contacts.html`.
- Добавлена единая Bootstrap-навигация (`navbar`).
- Использованы компоненты: `card`, `btn`, `badge`, `alert`, `modal`, `accordion`.
- Добавлена форма бронирования с `form-control`, `form-select`, `input-group`, `form-check`.
- Обновлен `css/custom.css`.

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог услуг;
- `product.html` — страница услуги;
- `order.html` — форма бронирования;
- `contacts.html` — контакты и FAQ;
- `css/custom.css` — дополнительные стили;
- `README.md` — описание проекта.

## Как проверить
Откройте `index.html` в браузере. Проверьте работу модального окна «Быстрая заявка», переключение страниц через навигацию и отображение компонентов на мобильных устройствах (через DevTools).
